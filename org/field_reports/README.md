# Field reports — what the fresh-session operators actually found

Mirrored here by the R&D cycle (board item **P3**, approved by the CEO 2026-09-25).

**Why this directory exists.** The four venture operators write their run logs to the Google Drive
folder. The Red Team, and any future agent, read the git repo and **have no Drive tools** (KB-104).
Without this mirror their findings are invisible to exactly the agents whose job is to audit them —
which is the defect that cost this organization KB-110.

One file per operator, holding its latest `FOR THE CONTROL PLANE` section verbatim plus a dated
header. Refreshed each R&D cycle. **These are quotations, not summaries** — where a number matters,
it is the operator's own.
