# org/ — the LIFE ZERO control plane

**Read this before acting. Write back to it after.**

LIFE ZERO is not a Gumroad company, not a digital-product company, not an automation agency.
Those are hypotheses. LIFE ZERO is **an autonomous economic organization searching for the most
effective legitimate way to turn resources into profit.** The only score is
**revenue − expenses = profit.** Commits, agents, products, research, automation and traffic are
not success.

Established by owner directive, 2026-09-24, which corrected a drift: Gumroad was meant to be one
experiment and had become the centre of the organization.

## The files

| File | What it is | Who writes it |
|---|---|---|
| `CONTROL_PLANE.md` | Current objective, strategy, ventures, owners, gates, scheduled actions, money. **The single source of truth for "what is going on".** | Any agent, on a material change |
| `KNOWLEDGE_BASE.md` | Every failed experiment, why it failed, and what would have to change to retest it. **Consult before proposing anything.** | Any agent, on a kill |
| `RD_CHARTER.md` | The R&D function's mandate, independence and reporting line | CEO |
| `RD_BOARD.md` | Live R&D output: opportunities, models, channels, architecture problems, proposed and killed experiments | R&D agent |
| `OPPORTUNITY_SCORING.md` | The 13-factor rubric and the experiment template. No experiment runs without one. | R&D proposes, CEO approves |
| `../growth/OPERATORS.md` | Who else is running, what they own, where they collide | CEO |

## The rules that make this work

1. **Read before acting.** Any agent, at the start of any cycle: read `CONTROL_PLANE.md` and the
   relevant section of `KNOWLEDGE_BASE.md`. If you are about to try something, check it has not
   already failed.
2. **Write back material discoveries.** Not activity — discoveries. A result, a dead end, a
   channel that works, a gate that opened.
3. **Sunk cost has zero voting rights.** Nothing is preserved because it was built.
4. **No experiment runs indefinitely because an agent likes it.** Every one has a kill condition
   and a date.
5. **Access beats product.** Before substantial build: *where exactly does the first customer come
   from?* No credible answer → do not build.
6. **Owner minutes are capital.** Optimise for minimal *recurring* owner labour, not zero owner
   action. A one-time 5-minute gate that unlocks months of autonomy can be the best trade
   available.

## The known architectural defect

Most LIFE ZERO agents run **from a fresh session every six hours with no memory**. They cannot read
this repo. That is the root cause of the duplicated analysis, conflicting ownership, stale
instructions and near-miss destructive overwrite documented in `../growth/OPERATORS.md`.

**A control plane only works if every agent can reach it.** This repo is reachable by the
persistent founder-operator session. The shared medium available to *all* agents is the Google
Drive folder "LIFE ZERO" (`1HBEz3p2D2EbaLBLr_iH5Ygp-Xtwt8bM0`). Publishing the control plane there,
and adding a "read it first" line to every operator prompt, is tracked as the top organizational
experiment on `RD_BOARD.md`. Until that is done, this directory is honest about its own limit: it
is shared state that only one agent can currently read.
